# Ollama Local AI
![Ollama logo](ollama_logo.png)

Exploring local AI with Ollama, including model setup, testing, and troubleshooting.

## Project Overview

This project documents my experience setting up and using Ollama to run AI models locally on my Linux laptop.

It covers my original setup, restoring Ollama after a Linux Mint filesystem failure, and testing local models for cybersecurity learning. I compared responses from two Qwen 2.5 model sizes using a question about the CIA triad.

This is an independent learning project and is not affiliated with Ollama.
