# Ollama Local AI
![Ollama logo](ollama_logo.png)

Exploring local AI with Ollama, including model setup, testing, and troubleshooting.

## Project Overview

This project documents my experience setting up and using Ollama to run AI models locally on my Linux laptop.

It covers my original setup, restoring Ollama after a Linux Mint filesystem failure, and testing local models for cybersecurity learning. I compared responses from two Qwen 2.5 model sizes using a question about the CIA triad.

This is an independent learning project and is not affiliated with Ollama.

## Environment

| Component | Details |
| --- | --- |
| Current operating system | Linux Mint 22.3 |
| AI runtime | Ollama |
| Interface | Linux terminal |
| Service management | systemd |
| Deployment | Local installation without Docker |
| Models tested | Qwen 2.5 0.5B and 3B |

## Project Milestones

- Set up Ollama locally on Linux.
- Restored the configuration and reinstalled Ollama after a filesystem failure.
- Verified the Ollama service and local API.
- Downloaded and tested two Qwen 2.5 model sizes.
- Compared their answers to a cybersecurity question about the CIA triad.
